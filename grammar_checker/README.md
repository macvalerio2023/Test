# Grammar and Punctuation Checker

This web application checks text for grammar and punctuation errors.

## Setup

1.  **Install the required Python packages:**

    ```bash
    pip install -r requirements.txt
    ```

2.  **Download the language tool data:**

    The first time you run the application, it will download the necessary language data. This may take a few minutes.

## Running the Application

1.  **Navigate to the `grammar_checker` directory:**

    ```bash
    cd grammar_checker
    ```

2.  **Start the Flask server:**

    ```bash
    flask run
    ```

3.  **Open your web browser and go to:**

    [http://127.0.0.1:5000](http://127.0.0.1:5000)

## How to Use

1.  Enter the text you want to check into the text area.
2.  Click the "Check Text" button.
3.  The results will be displayed below the text area.
